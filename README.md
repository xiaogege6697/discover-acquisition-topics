# 获客选题研究 Skill（discover-acquisition-topics）

> 研究并排序"真正能带来客户"的内容选题——基于当下需求信号、客户原话、触发场景、竞争拥挤度与服务承接能力，而不是凭感觉拍脑袋。
>
> Research and rank customer-acquisition content topics for any industry, using live demand signals, customer verbatim, trigger moments, competition density, and service fit — before you publish.

## 为什么做这个

做内容获客最常见的失败不是"没流量"，而是"有流量没客户"：

- 选题靠通用经验拍脑袋，没有验证过当下有没有人在搜、在问、在付钱；
- 追热点做出了爆款，吸引来的却是同行、围观党和白嫖党；
- 话题有需求但太拥挤，发出去就沉底；
- 话题有空白但承接不了，客户来了也接不住、转化不了。

这个 Skill 把"选题"当成一次小型市场研究来做：先搞清楚**谁在什么时刻因为什么难受/想要什么**，再判断竞争密度和你的服务能不能接住，最后给出可测试的选题清单和转化路径。它不承诺爆款，它提高的是"内容换来的对话质量"。

## 核心标准

一个强获客选题 = **具体的人 × 触发时刻 × 真实痛点/欲望 × 决策缺口 × 可信证据 × 服务桥梁**

让对的人看到后依次想到：

1. 这说的就是我；
2. 这件事值得解决；
3. 这个人懂我的决策；
4. 我知道下一步该找谁、做什么。

高播放不等于高获客。优先看合格咨询、预约、付费诊断、成交、毛利、复购与转介绍。

## 核心特性

- **七要素信息采集**：业务、客户、服务、需求、平台、转化目标、证据——缺核心字段时一次性批量提问（最多 5 个），不甩长问卷，也不默默编造。
- **购买引擎分类**：问题修复 / 目标改善 / 欲望与身份 / 便利 / 组织回报——避免给欲望型赛道硬套恐惧型内容。
- **四层证据收集**：需求（客户原话）、竞争（内容饱和度与被忽视的问题）、经济性（付费意愿与能力）、背景（政策/季节/平台变化）。一手数据（CRM、客服记录、访谈）优先于公开网络数据。
- **需求旅程地图**：从"无意识 → 感受到症状 → 知道问题 → 知道方案 → 比较供应商 → 行动"，专找用非专业语言表达痛点的人群、关系/生命周期过渡期、新职业新行为新法规等空白。
- **拥挤度四象限审计**：高需求高竞争 / 高需求低供给 / 低显性需求但可信潜在需求 / 双低——不同象限不同打法，不把"没人做"误当机会。
- **15+ 候选与 100 分评分**：12 个维度打分（客户具体性、触发清晰度、需求证据、付费意愿、竞争空白、服务承接等），外加风险调分与一票否决项（编造事实、欺骗性稀缺、保证结果、制造恐惧等直接出局）。
- **转化路径设计**：每个入围选题配齐钩子、证据、互动提问、筛选问题、下一步 offer 与负责人——允许"自助""还没准备好""不合适"出口，不把所有人硬塞进销售漏斗。
- **小成本测试计划**：先测 3-5 个选题，一次只变一个变量；度量合格私信、筛选完成率、预约率、付费率，播放点赞只作诊断信号。
- **受监管行业约束**：法律、医疗、金融、教育等场景自动启用合规约束——查权威来源、区分科普与个案建议、不承诺结果、诊断与交付交给有资质的专业人士。

## 边界

- 不制造恐惧、冲突、疾病焦虑或诉讼恐慌；只揭示真实存在的需求和可能性。
- 不发明搜索量、转化率或市场规模；假设、推断与证据缺口一律显式标注。
- 把"低显性需求"与"没有可行需求"区分开，不为可吓唬的人群断言机会。
- 受监管行业中区分科普与个案专业建议，不承诺结果，诊断与交付交给有资质的人。
- 平台算法按黑箱对待：只用可观察行为与官方指引，不把玄学当事实。
